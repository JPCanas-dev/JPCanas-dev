<h2 id="proyectos-destacados">🚀 Proyectos destacados</h2>

<h3>🛠️ <a href="https://github.com/JPCanas-dev/finalSpringBoot-HelpFlow" target="_blank">HelpFlow – Sistema automatizado de gestión de tickets</a></h3>
<p>
  <i>Desarrollador Backend • Proyecto individual</i><br /><br />
  Plataforma de tickets de soporte técnico diseñada para asignar solicitudes automáticamente a técnicos disponibles y monitorear tiempos de resolución. 
  Diseñada bajo Arquitectura Hexagonal en Java y Spring Boot, cuenta con control de acceso basado en roles mediante JWT, 
  migraciones de base de datos con Flyway en PostgreSQL y contenedorización con Docker para un despliegue ágil.
</p>
<p>
  <b>Tecnologías:</b> Java, Spring Boot, Spring Security (JWT), REST APIs, PostgreSQL, Flyway, Docker, Postman, Swagger UI, GitHub.
</p>

<h3>💳 <a href="https://github.com/Danilo-Doria/SkillBridge-AI-JAVA-Angular" target="_blank">SkillBridge AI – Plataforma de mentorías y servicios profesionales</a></h3>
<p>
  <i>Desarrollador Full Stack • Proyecto en equipo</i><br /><br />
  Aplicación web con simulación de flujo completo de pagos mediante Stripe. Desarrollé una pasarela segura en el frontend utilizando Angular y componentes de Stripe, 
  implementando la lógica del backend en Spring Boot con webhooks automatizados para registrar y actualizar el estado de cada transacción en tiempo real.
</p>
<p>
  <b>Tecnologías:</b> Java, Spring Boot, Angular, Stripe API, Stripe Elements, Stripe CLI, REST APIs, JUnit, Mockito, GitHub.
</p>

<h3>👥 <a href="https://github.com/Zolagos/PROYECTO-MENTORIA-Y-RETROALIMENTACION" target="_blank">TutorCode – Plataforma de mentorías y retroalimentación</a></h3>
